## 👋 About me

I'm a software developer focused on **Rust**, **Go**, **TypeScript**, and **Kotlin**. I like building fast, secure, local-first software — desktop and mobile apps, systems tools, and small web apps that do one thing well.

- 🦀 Building desktop and cross-platform apps in Rust with Tauri and Dioxus
- 🐹 Writing small, dependency-free tools in Go
- ⚛️ Shipping React + TypeScript apps to GitHub Pages
- 📱 Building Android apps in Kotlin
